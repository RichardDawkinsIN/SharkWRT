# SharkWRT

An Android app to manage your OpenWrt router from your phone over SSH.

SharkWRT is a fork of [WrtPulse](https://github.com/iamvivekkaushik/WrtPulse) by Vivek Kumar, with a new liquid-glass UI.

## Features

- Dashboard with CPU, RAM, uptime and live speed
- Connected devices (rename, block, wake-on-LAN)
- Wi-Fi, guest Wi-Fi, LAN, WAN and mesh settings
- Firewall and static routes
- SSH terminal
- Logs, packages, services, firmware, backup and restore
- Light/dark themes and accent colours

No agent is installed on the router. The app just connects over SSH and runs normal OpenWrt commands.

## Requirements

- Android 9 or newer
- OpenWrt router with SSH enabled
